# Sistema de Gerenciamento e Reserva de Laboratórios 🧪

Software desenvolvido em C para gerenciar a reserva de laboratórios acadêmicos. O foco principal do projeto foi a eliminação de conflitos de horários e duplicidade de agendamentos, utilizando conceitos avançados da linguagem.

## 🚀 Funcionalidades e Destaques
- Sistema de agendamento que impede conflitos de horário e duplicidade.
- Implementação avançada de gerenciamento de memória através de ponteiros e estruturas dinâmicas.
- Tratamento estrito de regras de negócio complexas e otimização lógica.
- Armazenamento de informações em arquivos de dados locais (`.dat`).

## 🛠️ Tecnologias e Conceitos Aplicados
- **Linguagem:** C
- **Conceitos:** Alocação Dinâmica de Memória, Estruturas de Dados, Ponteiros
- **Ferramentas:** Visual Studio Code, GCC Compiler

## ⚙️ Como executar o projeto na sua máquina

1. Clone o repositório:
`git clone https://github.com/JoseBreno2026/reserva-laboratorios-c.git`

2. Navegue até a pasta do projeto e compile o código utilizando o GCC:
`gcc main.c laboratorio.c -o sistema_reservas`

3. Execute o programa gerado:
No Windows (pelo terminal ou Git Bash):
`./sistema_reservas.exe`
No Linux/Mac:
`./sistema_reservas`
